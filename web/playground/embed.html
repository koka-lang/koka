Koka Embeddable Editor

Interactive Koka code examples that compile and run in the browser. Each editor shares a single WASM compiler instance.

Hello World

The classic first program — click ▶ Run to compile and execute:

fun main() println("Hello, Koka!")

Effects

Koka tracks side effects in the type system. This example uses the console effect:

fun greet(name : string) : console () println("Hello, " ++ name ++ "!") fun main() greet("World") greet("Koka")

Pattern Matching

Koka supports pattern matching on algebraic data types:

fun fibonacci(n : int) : div int match n 0 -> 0 1 -> 1 _ -> fibonacci(n - 1) + fibonacci(n - 2) fun main() list(0, 10).foreach fn(i) println(fibonacci(i).show)

Read-Only Example

This example is read-only (no editing, no run button):

// Type inference example val xs = [1, 2, 3] // xs : list val ys = xs.map(show) // ys : list

Custom Function

Examples with fun test/... or fun example/... are also runnable:

fun example/counter() var count := 0 repeat(5) count := count + 1 println("Count: " ++ count.show)
